# CreatorFlow 第一阶段 PRD（v0.1.0）

## 1. 目标

打通并验证以下闭环，作为后续所有功能的地基：

> 启动应用 → 创建作品 → 自动创建目录与 manifest → SQLite 写入作品与分区 → 导入素材 → 素材列表 → 关闭重启后恢复。

验收标准：使用文档、图片、音频、视频四类样本完成导入与重启测试；源文件不变；数据库与磁盘一致；错误不会静默丢失。

## 2. 本阶段范围

### 2.1 作品管理

- 首页展示最近作品、作品总数与创建入口。
- 新建作品：名称（必填）、描述（可选）、作品根目录（可沿用全局设置）。
- 创建时生成 UUID、作品目录、四个分区目录（`01_文档`、`02_音频`、`03_视频`、`04_图片`）与 `creatorflow.manifest.json`。
- 作品名称校验：空值、首尾空格、Windows 非法字符、保留设备名、长度、结尾句点。
- 支持打开、重命名（含磁盘目录重命名与失败回滚）、归档（仅改状态，不移动文件）。
- 作品状态：构思中 / 脚本编写 / 素材收集 / 制作中 / 待审核 / 已发布 / 已归档；可手动切换前六种。
- 不提供永久删除。

### 2.2 素材导入

- 系统文件对话框多选；支持窗口拖入；两者都保留。
- 按扩展名给出分区建议，导入前可逐文件调整；无法识别类型的文件不会被静默丢弃（默认落到当前分区并在对话框中标记「类型未识别」）。
- 默认**复制**并保留源文件；绝不移动、重命名、修改源文件。
- 1 MB 缓冲区流式复制，不整文件读入内存；后台线程执行，UI 不冻结。
- 先写临时文件（`.<名称>.<随机>.part`），校验大小后重命名为正式文件。
- 目标同名绝不覆盖，自动追加 ` (1)`、` (2)`。
- 任务状态：`queued → copying → verifying → completed`，其他终态 `failed` / `cancelled`。
- 进度事件（节流 180 ms）驱动界面进度条；失败显示原因并可重试。
- 启动时检查非终态任务，依据磁盘实际状态恢复：目标完整 → 补登记并完成；否则标记失败并清理临时文件。

### 2.3 素材浏览

- 四个分区间切换，展示名称、类型、大小、导入时间、状态。
- 当前作品内按名称搜索；按名称 / 大小 / 导入时间升降序排序。
- 图片基础预览（后端读取并返回 data URL，上限 24 MB）。
- 「使用默认程序打开」与「在资源管理器中显示」。
- 磁盘文件缺失时标记 `missing`，保留记录并提供提示；文件恢复后自动回到 `ready`。

### 2.4 设置

- 作品根目录选择与保存（系统目录对话框）。
- 展示应用版本、Tauri 版本、数据库路径、日志目录。

## 3. 明确不做（本阶段）

- 内置音视频/图像编辑器、AI 能力、节点式工作流、云同步与账号。
- 媒体元数据解析、视频缩略图、音频波形、PDF 内嵌预览。
- 完整回收站与软删除 UI、批量重命名、哈希去重。
- 自定义分区、模板编辑器、任务清单与标签。

## 4. 关键约束

- 前端不直接访问数据库或任意文件系统；仅通过显式强类型命令与事件。
- 所有用户可控路径经规范化校验，禁止 `..` 穿越出作品根目录。
- 迁移失败即停止写入，不带着未知结构继续运行。
- 错误信息面向用户为中文；原始技术细节只进日志。
